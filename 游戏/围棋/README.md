# 围棋 · 双人对弈

双击 `index.html` 即可玩，纯本地运行，无网络请求。

## 玩法

- 对手可选：**双人**（同设备轮流点）或 **电脑**（简单/中等/困难，可执黑或执白）。
- 9 / 13 / 19 路棋盘可选（开新对局时选择）。
- 右上角可切换棋盘风格（木纹 / 樱花 / 江南烟雨）、开关"确认落子"（点一下出影子，再点一下才落）。
- 按钮：虚手（放弃一手）、悔棋、认输、新对局。对 AI 悔棋一次退一整轮。
- 双方连续虚手即终局，进入数子：红 ✕ 是系统预标的死子，**自动判定可能有误，点击棋块可切换死/活**，确认后出结果。
- 关掉页面再打开会自动恢复上局；恢复时轮到电脑就接着想。
- AI 落子过程分片计算，页面不冻结；AI 的每步招法都会先过规则裁判（含全局同形检查）。

## 规则

中国规则 · 数子法：得分 = 盘上棋子 + 围住的空点，白棋贴 7.5 目（即黑贴 3¾ 子）。
禁着点不许自杀；不得重现任何曾出现过的整盘局面（打劫须先在他处落子寻劫）。

## 文件结构

- `js/engine.js` —— 规则引擎（气/提子/禁着点/全局同形/数子/死子预判），UMD 可被 node 单测
- `js/go-mcts.js` —— AI：蒙特卡洛树搜索（UCT + 先验渐进偏置 + 战术快棋 + 目差梯度奖励），
  三档难度只是思考预算不同（简单 0.6s/150 盘、中等 1.5s/1200 盘、困难 9路1.2s/13路1.8s/19路2.6s 限时）。
  搜索分片执行（file:// 下不用 Web Worker），node 里可用 genMoveSync 做 arena 测试
- `js/app.js` —— 界面与对局流程
- `css/style.css` —— 样式
- `assets/sakura-board.png` —— 樱花棋盘底图（AI 生成，绘制时裁掉底部水印区）
- `assets/jiangnan-board.png` —— 江南烟雨棋盘底图（AI 生成水墨风，同上裁水印）
